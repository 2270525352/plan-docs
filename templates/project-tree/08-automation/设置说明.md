# Codex App 定时审查设置说明

1. 先确认 `06-reviews/自动模式门禁.md` 为 READY。
2. 让用户确认是否启用、项目路径、基线和每 30 分钟频率。
3. 在当前 Codex App 中创建独立自动化，并粘贴 `Codex App定时审查提示词.md`。
4. 确认自动化使用独立上下文，并说明它能看到 committed、pushed 和未提交状态中的哪些部分。
5. 先手动运行一次，验证能读取目标项目并输出 GREEN/YELLOW/RED。
6. 默认只报告；如需持久化报告，另行取得写入 `06-reviews/` 的授权。
7. 不支持所需调度或隔离能力时，保留提示词并报告降级，不声称已启用。
