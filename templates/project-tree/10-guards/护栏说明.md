# 护栏说明

使用 `scripts/plan-docs-guards.py` 安装、校验或卸载。

能力：

- Claude 写入工具的实时范围提示/拦截；
- Claude 结束前执行反馈检查；
- Git staged 文件的 allowed_scope/forbidden_scope/write_lock 检查；
- 用户原话 staged diff 的 append-only 检查；
- 业务任务反馈、验证和测试门禁；
- commit message 的 task ID/执行 AI 格式；
- pre-push 阻止强制更新，不固定禁止 main/master。

限制：

- 不同 AI/CLI 对 hook 的支持不同；Git hooks 是通用的提交期后盾。
- shell 命令或外部程序可能绕过实时写入 hook，仍需 staged scope 检查和 Reviewer。
- 已有 `core.hooksPath` 或 linked worktree 共用默认 hooks 时安装器不覆盖或改写共享配置。必须在 `git rev-parse --git-path hooks` 实际解析出的三个 hook 中显式调用对应的 `.plan-docs/git-hooks/<hook>`，再运行 `verify --allow-existing-hooks-path`。
- 护栏不能替代需求确认和六代理审查。

安装：

```bash
python3 <skill-dir>/scripts/plan-docs-guards.py install --project <project>
python3 <skill-dir>/scripts/plan-docs-guards.py verify --project <project>
```

已有 hook manager 且完成三项串联时：

```bash
python3 <skill-dir>/scripts/plan-docs-guards.py verify --project <project> --allow-existing-hooks-path
```

卸载只移除 Plan Docs 自有文件和 settings 条目：

```bash
python3 <skill-dir>/scripts/plan-docs-guards.py uninstall --project <project>
```
